# dotconfig

- `/nvim` Just the config of my LazyVim
- [`/pi`](pi/README.md) Global Pi extensions, symlinked from dotconfig (including Neovim review feedback)
- `/mise` Polyglot version manager config (replaces nvm, pyenv, rbenv, etc.)
- `dnvim` - contains a cli tool to install lazyvim in a running docker container
- `scripts/bitwarden-bootstrap.sh` — one-command setup for Bitwarden CLI on new machines
- `scripts/init_mac.sh` — Bootstrap script for new Mac setup (installs brew packages, mise, rust, etc.)
